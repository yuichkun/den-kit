# den-kit（PoC・GEN-648）

den のブロックを Bitwig Grid のようにパッチングし、そのグラフがそのままプラグインの音とパネル（UI）になる制作環境の試作です。

- CP1（AI なしのパッチング環境）と CP2a（AI の速い経路：語彙表と Jev）は、この README の手順で動きます。
- CP2b（LLM のテイクと聴くツール）は、このあと同じ `kit/` に追加します。

## はじめかた（Mac）

den リポジトリのルートで次を実行します。

```sh
npm ci                # den 本体の依存
npm run kit:setup     # kit の依存を入れ、den をビルド
npm run kit:doctor    # 環境の確認（失敗した項目には直し方が出ます）
npm run kit:dev       # http://127.0.0.1:5180/ を Chrome で開く
```

- 音は 48 kHz で動かします。出力デバイスが 44.1 kHz のときは、「Audio MIDI 設定」で 48 kHz に変えてください。48 kHz でない場合は、画面にその旨が表示されます。
- 開くと画面全体に「Click anywhere to start」が出ます。どこかをクリックするかキーを押すと、音と MIDI 入力が始まります（ブラウザの決まりで、ページを開いただけでは鳴らせないためです）。音が出せないとき（48 kHz でないなど）は、同じ画面に理由が出ます。
- 起動すると bass のスターターが読み込まれます。画面下の鍵盤をクリックするか、鍵盤に書いてある PC キー（A W S E D F T G Y H U J K。Z / X でオクターブ）か、MIDI キーボードで鳴らします。`⌘.` で全部の音を止めます。

## AI の速い経路（CP2a）

**準備（初回だけ）**
1. `kit/.env` を作り、`TYPESAFE_API_KEY=…` の 1 行を書きます。このファイルは git に入りません。キーはブリッジ（Node）だけが読み、ブラウザには渡しません。
2. `npm run kit:doctor` で「Jev key」と「Jev request」が PASS になることを確かめます。Jev への小さな要求を 3 回送り、所要時間を表示します。
3. `npm run kit:eval:jev` で、英語と日本語の例文（`kit/scripts/eval-jev.fixtures.json`）を本物の Jev に解かせます。正答率と τ の表が出ます。τ を決める目安にします。結果は `kit/.logs/` に保存されます。

**使い方**
- `npm run kit:dev` を起動すると、AI ブリッジ（127.0.0.1:5181）も一緒に起動します。右上に `Jev 230 ms` のような状態が出ます。
- 画面下の大きな入力欄に依頼を書いて Enter を押します（`Enter` か `⌘K` で入力欄に移ります）。例：「明るく」「リリース長く」「もっと揺らして」「リバーブ足して」「ベース作って」「a bit darker」「add reverb」。
- 変更はすぐに適用されます。入力欄の上に、直近の依頼と結果（変えた値とかかった時間）が並びます。入力欄は送るたびに空になるので、そのまま次の依頼を続けられます。
- 気に入らなければ、普通の取り消しと同じく `⌘Z` で戻します。AI の変更 1 回分が 1 回で戻り、履歴には「undone」と出ます。
- **音声入力**：Space を押している間だけ聞き取り、離すと送信します。何度でも同じ操作で話せます。入力欄の中でも使えます（短く押すと空白が入り、長く押すと話せます）。ほかの文字欄（パッチ名、検索、コード）では普通の空白です。マイクのボタンをクリックしても始められます。
  - Chrome の音声認識を使います。音声は Google のサーバーで文字に変換されます。
  - 初回は Chrome がマイクの許可を求めます。
  - 聞き取る言語は日本語です。英語にするときは ⚙ の「Voice language」で切り替えます。
- よく使う言い回しは語彙表がその場で処理し、Jev は呼びません。語彙表で分からない部分があるときだけ、Jev に 1 回だけ問い合わせます。
- 自信が τ に届かないとき、待っている間にパッチが変わったとき、対象のモジュールが絞れないときは、変更せずに解釈の候補（チップ）を出します。押すと適用されます。
- コードを書く・配線を組み替えるなどの依頼は「LLM の経路（CP2b）」と表示されます。
- ⚙ で開発用の引き出しが開きます。τ（英語・日本語）、Jev の持ち時間、音声の言語、Jev の使用の有無を変えられます。直近の依頼の記録（経路・確信度・時間）も見られます。
  - 既定値は、2 回目の `kit:eval:jev`（36 本すべて正解、応答 160〜360 ms）をもとに決めています：τ は英語 0.60・日本語 0.70、Jev の持ち時間は 1.2 秒。
- 記録は `kit/.logs/trace-*.jsonl`（依頼ごとの経路・確信度・時間・取り消し）と `kit/.logs/jev-*.jsonl` に書かれます。
- キーがない、Jev に届かない、ブリッジがないときも、語彙表の操作と CP1 の機能はそのまま使えます。

## 画面

**Patch（パッチ）**：上部のパレットからモジュールをドラッグするかクリックして置きます。キャンバスでダブルクリックするか Tab を押すと検索が開きます。
- 出力の点（右）から入力のリング（左）へドラッグすると、ケーブルがつながります。
- 入力の色は信号の種類を表します。
  | 色 | 信号 |
  |---|---|
  | 赤 | オーディオ |
  | オレンジ | ピッチ・周波数 |
  | 緑 | 時間・エンベロープ |
  | 水色 | LFO 出力 |
  | 青 | その他の値 |
  | 黄 | ゲート |
- つながっていない入力はつまみ（AudioParam）です。回しても再コンパイルは起きません。
- モジュール表面の大きなつまみがよく使う値です。残りの値は左のインスペクタにあります。「+N」を押すと入力が全部表示されます。
- 入力の横の ↺／⎍／↑ はプリコードです。つながっていない間は、ノートの gate・新しいノート・パニックに自動で従います。
- **Voice In** から **Voice Mix** までのモジュールは、声の数だけ複製されます（左上の重なったアイコンで分かります）。
- フィードバックは **History**（1サンプル遅延）を通すときだけつなげます。
- **Codebox** には unworklet の core API でコードを書けます。エラーは該当する行に表示されます。

**Panel（パネル）**：左のパネルの「→ Panel」で入力をつまみとしてパネルに出せます。
- 「Edit layout」で配置と大きさを変えられます。
- テーマは 4 種類です。

**Code（コード）**：生成された unworklet プロセッサを読み取り専用で表示します。選んだモジュールの行が強調されます。

**その他**
- `⌘Z` / `⇧⌘Z` で取り消しとやり直しができます（ボタンはありません）。つまみをひと回しした操作や AI の変更 1 回分は、1 回で戻ります。
- 左上の **Patch ▾** から、スターターを開く・`.denkit.json` の書き出しと読み込みができます。自動保存はブラウザ内です。
- モジュールを選ぶと、左のパネルにすべての設定が出ます。エフェクトのパッチでは、**Audio In** を選ぶと試聴用の入力（和音・ドラム・ノイズ）を切り替えられます。
- パッチ全体の問題と、暴走した音の安全ミュートは、キャンバス上部の帯に出ます。ミュートは、パッチを変えるか `⌘Z` で戻すと自動で解除されます。

## 仕組み（要点）

- **パッチの形式**：パッチは JSON の文書です。変更はすべて「作者つきの型付き操作」（`src/core/ops.ts`）を通り、正確に元に戻せます。人も AI も同じ操作を使います。
- **コード生成**（`src/core/codegen.ts`）：パッチを、読める unworklet core API の TS（1つの `defineProcessor`）にします。それを Worker でコンパイルし、AudioWorklet として差し替えます。差し替えには約 30 ms のクロスフェードをかけ、押さえている鍵盤のノートは新しい音へ送り直します。
- **unworklet 0.4.1 での注意**：0.4.1 は式の DAG を展開してしまいます。そのため、2回以上読む信号と den ブロックへの入力は、サンプルごとに1回だけ一時スロットに書いてから読みます。
- **den との一致**：スターター 5 本（bass、percussion、pad、chorus、rhythmic delay）はモジュールの組み合わせだけで作っています。オフライン描画では、den の `createInstrument` や `delayFx` とサンプル単位で一致します（`test/integration/equivalence.test.ts`）。音は CANDIDATE です。
- **安全段**：リミッター → クリップの順に通します。NaN や暴走はプロセッサ内で検出して知らせます。その場合はミュートして状態をリセットします。

## テスト

```sh
npm run kit:test   # unit（vitest）→ integration（実コンパイル・オフライン描画・ブリッジ）→ e2e（Playwright + Chromium）
```

テストでは本物の Jev を使いません。`test/fakes/jev` の模擬サーバが、要求を本物と同じ規則で検査し、401・422・429・529・時間切れ・壊れた JSON・確率の異常などを再現します。

e2e には Chromium が必要です。手元にない場合は `npx playwright install chromium` で入れるか、`CHROMIUM_PATH` を指定してください。
