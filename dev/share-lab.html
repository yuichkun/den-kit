Link preview lab

Every link this den-kit has made, as four kinds of chat app would show it when the link is pasted. What each preview holds is what this server's unfurler read in the link's page, as apps read it, without running the page. How it is laid out is this page's own drawing of each kind of app, not the app: check a real app before deciding on anything that depends on it. Links point to 127.0.0.1, which real apps cannot reach.

Stopped links

A stopped link opens nothing, but the preview taken when it was pasted stays with that message. Apps also reuse what they read for a link for a while (Discord says about 30 minutes), so pasting it again soon after can still show the old preview; "Read the pages again" reads without that reuse.
