# Showcase pictures: where they come from

den is a public repository, so the showcase only uses pictures that are CC0,
public domain, or made for den-kit (own work, Apache-2.0 like den). Licences
were checked on 2026-10-07 against each source's own metadata (Wikimedia
Commons `LicenseShortName`, the NPS record, the ambientCG licence page). The
photos are re-encoded JPEGs (sRGB, longest side 1600 px or a 1024 px square
crop, metadata removed). None shows a brand, a logo or a person.
