# Changelog

Release pull requests add a dated version section here (`## X.Y.Z — YYYY-MM-DD`).
Unreleased entries describe the main branch and are not yet available as an app download.

## Unreleased

- Signed and notarized macOS packages for Apple silicon and Intel, published to
  GitHub Releases from reviewed release pull requests.
- In-app updates: den-kit downloads a new version in the background and installs
  it the next time you quit, or right away when you choose **Restart now** in
  Settings. Your work is saved first, and den-kit never restarts on its own.
- den-kit offers to move itself into the Applications folder, where updates can
  be installed.
